# Stockify AI

A full-stack AI-powered web application for beginner investors to analyze stocks, track their portfolio, and get ML-driven investment recommendations.

## Architecture

* **Frontend**: React.js with React Router, Recharts, and custom CSS
* **Backend**: Java Spring Boot 3 with Spring Security and Spring Data JPA
* **Database**: MySQL 8
* **AI Microservice**: Python Flask with Scikit-learn and VADER Sentiment Analysis

## Prerequisites (for local development)

* Java 21+ and Maven
* Node.js 18+ and npm
* Python 3.10+ and pip
* MySQL 8+

*(Alternatively, you can just use Docker and Docker Compose to run everything without installing these locally).*

## Quick Start (Docker)

The easiest way to run the entire application is using Docker Compose:

1. Install [Docker Desktop](https://www.docker.com/products/docker-desktop/)
2. Open a terminal in the project root directory
3. Run:
   ```bash
   docker-compose up --build -d
   ```
4. Wait a minute for all services to start
5. Access the application:
   * Frontend: http://localhost:3000
   * Backend API: http://localhost:8080/api/
   * AI Service: http://localhost:5000/health

## Running Locally (Without Docker)

If you want to run the services individually for development:

### 1. Database Setup
Create a MySQL database named `stockify_db` with username `root` and password `root`.
```sql
CREATE DATABASE stockify_db;
```

### 2. Spring Boot Backend
```bash
cd stockify-backend
mvn spring-boot:run
```

### 3. Python AI Service
```bash
cd stockify-ai
pip install -r requirements.txt
python app.py
```

### 4. React Frontend
```bash
cd stockify-frontend
npm install
npm start
```

## Features

1. **User Authentication**: JWT-based login and registration.
2. **Dashboard**: View trending stocks, market news, and a high-level portfolio overview.
3. **Stock Search & Detail**: Search for any stock symbol (e.g., AAPL). The detail page provides fundamental metrics (P/E ratio, Market Cap, etc.) with beginner-friendly explanations.
4. **AI Recommendations**: View Buy/Hold/Sell predictions generated by a simulated Machine Learning model based on technical indicators.
5. **News Sentiment Analysis**: View real-time (simulated) news articles analyzed by VADER NLP to gauge market sentiment (positive/negative/neutral).
6. **Portfolio Management**: Add stocks to your portfolio, track total value, and calculate historical Profit/Loss (P/L).

## Note on Data
This project currently uses generated/simulated data for demonstration purposes, ensuring it works perfectly out-of-the-box without requiring you to sign up for external API keys (like Alpha Vantage or Yahoo Finance).
